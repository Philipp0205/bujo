# bujo

Private hybrid bullet journal: paper day pages, a digital backlog in Nextcloud Tasks (CalDAV VTODO), and an evening scan with a mandatory review before anything syncs.

Built as an app-kit PWA (pinned to v0.7.0), in the same shape as Hangry (free-now). The product brief lives in `docs/brief.md`.

This first version is a read-only backlog: a phone-sized list of open tasks with filters (all open, by tag, by priority, someday, scheduled). It has no write path to CalDAV yet.

## Run

Needs Node 22.5 or newer.

    npm ci
    npm start        # http://127.0.0.1:3000, demo data unless CalDAV is configured
    npm run dev      # same, restarts on change

With no CalDAV settings the server shows built-in demo tasks, so the UI works offline.

## Environment

| Variable | Meaning |
| --- | --- |
| `BUJO_CALDAV_BASE` | Origin of the CalDAV server, for example `https://cloud.example.com`. |
| `BUJO_CALDAV_USER` | Basic auth user. |
| `BUJO_CALDAV_PASSWORD` | Basic auth password (an app password is best). |
| `BUJO_CALDAV_LISTS` | `name=path` pairs, comma separated: `Aufgaben=/remote.php/dav/calendars/admin/tasks/,Arbeit=/remote.php/dav/calendars/admin/arbeit/` |
| `PORT`, `HOST` | Listen address. Default `3000` and `127.0.0.1`. |

Set `BUJO_CALDAV_BASE` and `BUJO_CALDAV_LISTS` together, or neither. Keep the values in your shell or an untracked `.env`, never in the repo.

Endpoints: `GET /healthz`, `GET /api/backlog` (open tasks; `?status=all` adds completed and cancelled), static files from `public/`.

## Layout

- `src/caldav/`: read-only CalDAV client (PROPFIND and REPORT only) and the ICS VTODO parser.
- `src/app-kit/`, `public/app-kit/`: vendored app-kit v0.7.0. Never edit these. Update with `scripts/sync.sh` from the app-kit repo.
- `public/`: the plain JS frontend, `css/styles.css` (accent tokens), `sw.js`, and `manifest.webmanifest` (generated by app-kit's `scripts/manifest.mjs` from `manifest.config.json`).
- `test/`: node:test unit tests against a fake CalDAV server on 127.0.0.1, and Playwright specs in `test/ui/`.

## Checks

    scripts/check.sh

Runs `npm ci`, `typecheck`, `build`, `test` and `test:ui` quietly (logs in `/tmp/check-bujo-*.log`), stops at the first failure and prints `all checks passed`. The UI tests use the system Chrome at 390x844, once in light and once in dark. Tests only talk to the fake CalDAV server, never to a real Nextcloud.
